### What is CHIP-8?

CHIP-8 is a programming language from the 1970s that made it into a few microcomputers of the time. It's designed to be pretty simple, so writing an interpreter for it isn't the most complex thing in the world.

To address the notation confusion, yes, you will technically be writing a CHIP-8 _interpreter_ here, not a CHIP-8 emulator. Literally everyone calls it an emulator though, so that's been mirrored here.

### But how does it work?

The CHIP-8 language doesn't look like other languages you've seen before. It's much more similar to something like Assembly, though I promise it's easier to get into than assembly.

Here are some great resources to learn from:

- [Tobias Langhoff's Blog](https://tobiasvl.github.io/blog/write-a-chip-8-emulator/): Phenomenal guide, detailing the whole process pretty much start to finish.
- [CHIP-8 Test Suite](https://github.com/Timendus/chip8-test-suite): This Github repo has a bunch of sample CHIP-8 programs designed to test your emulator.
- [Matthew Mikolay's CHIP-8 Wiki](https://github.com/mattmikolay/chip-8/wiki): This wiki is a good reference point for quickly looking things up. It has a list of instructions, reference for how the innards of CHIP-8 work, and more.

### What is needed to submit?

You need a program that can run the base CHIP-8 instruction set, and you need to have spent at least 10 hours making it. Trust me, that time requirement is something that you'll be hitting regardless.

There isn't much beyond that, but I would highly encourage you to use this opportunity to learn a new programming language! A CHIP-8 emulator is a great project for exploring the capabilities of that new language.

Also, where's the weirdest place that you can get CHIP-8 running? Just an idea for a fun challenge.

You could also look into the many, *many* extensions that are available for adding new instructions. Make this your own!

Notice your hours are starting to pile up from all the fancy features you're adding? If you cross **25 hours**, you can get a [LILYGO T-Deck Max](https://lilygo.cc/en-us/products/t-deck-max) instead! If you make it all the way to 30 hours, you can get both!
